# example-repo conventions

Non-obvious conventions this repo holds contributors to. Don't restate what
a linter or the code already enforces, only what a new contributor would
otherwise have to be told in person.

- _Example: "All background jobs go through the `jobs/` queue wrapper, never
  a raw cron entry. See `decisions/0001-job-queue-standardization.md`."_

Add an entry when a decision doc establishes a standing convention rather
than a one-off call, and link back to the decision that justifies it.
