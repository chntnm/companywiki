# master-brain index

Synthesized topic pages. **This directory is regenerated, never hand-edited**,
by anyone: `service_claude` or human. Edit the source `gh-brain`/`sp-brain`
doc and let regeneration pick it up. A hand-edit here is silently overwritten
on the next regeneration.

| Topic | Sourced from | Page |
|---|---|---|
| example | `gh-brain/apps/example-repo/`, `sp-brain/example-topic/` | [example.md](example.md) |

A topic gets a page here once it has content in *both* brains worth
reconciling. A topic living in one brain only doesn't need a synthesized
page; link the single source directly.
